# План правок по итогам ревью фронтенда

Источник находок: `bpmn-constructor/review.md` (2026-09-21). Фазы упорядочены по
риску для пользователя, каждая — самостоятельный коммит и проверяемый шаг.
Порядок внутри фазы можно менять, между фазами — не стоит: последующие опираются
на компоненты, появившиеся в предыдущих.

Общее правило правок: никакого нового цвета вне `src/styles/tokens.css`, никаких
новых контролов вне `src/components/ui/*`, ни одного выдуманного значения в UI.

Стенд для проверок (одноразовый, не трогает пользовательские `bpmn.db` и порт 3456):

```
DATABASE_URL="sqlite:///./verify_tmp.db" PYTHONIOENCODING=utf-8 python main.py   # 8765
cd bpmn-constructor && npm start                                                 # 3456
```

Замеры — puppeteer-скриптом из `node_modules` (`setViewport`, токен в
`localStorage.token`), не встроенным браузером: он отдаёт `innerWidth = 0`.

## Фаза 0 — Вернуть холст редактора (A1, A16, B20)

Проблема: панели ИИ и скоринга — обычные дети `.editor-container` с высотой `70vh`,
поэтому при открытии холст схлопывается до 0–10 px на 1366×768 и 1024×768. Пока это не
починено, любые другие правки редактора нельзя даже посмотреть.

1. `Editor.css`: дать `.editor-content` (`flex: 1 1 0; min-height: 0`) реальную строку
   раскладки; панели — оверлей внутри `.editor-canvas-area { position: relative }` либо
   сосед flex-элемент. Высоту панели задать токеном `--panel-height`, а не `70vh`.
2. `tokens.css`: добавить `--panel-height: clamp(320px, 60vh, 640px)` и `--color-scrim`.
3. `Editor.js:387-414`, `373`, `410`, `1054`: подсветка поиска — только
   `canvas.addMarker` на существующие правила `.djs-element.highlight`
   (`Editor.css:613-632`); убрать запись `di.fill` и литералы `'#ffffff'`
   (`Editor.js:51`, `971`) в пользу `--color-surface`.
4. `Editor.css`: скрыть `.bjs-powered-by`.

**Проверка:** при 1440×900, 1366×768, 1024×768 и 375×812 открыть «Сгенерировать» и
«Улучшить» — высота `.djs-container` не меньше 320 px; после поиска элемента и отмены
подсветки `saveXML()` байт-в-байт равен исходному.
