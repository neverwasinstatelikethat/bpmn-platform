# План правок по итогам ревью фронтенда

Источник находок: `bpmn-constructor/review.md` (2026-09-21). Фазы упорядочены по
риску для пользователя, каждая — самостоятельный коммит и проверяемый шаг.
Порядок внутри фазы можно менять, между фазами — не стоит: последующие опираются
на компоненты, появившиеся в предыдущих.

Общее правило правок: никакого нового цвета вне `src/styles/tokens.css`, никаких
новых контролов вне `src/components/ui/*`, ни одного выдуманного значения в UI.

## Принятые решения (2026-09-21)

1. **Лендинг** — зачистка выдуманного плюс настоящие артефакты вместо мока.
   Ограничение: рабочего ключа GigaChat в `.env` нет, поэтому живой скриншот ИИ-чата
   снять нечем. Реально захватываем: экспорт схемы из редактора (`Editor.js:971`),
   панель скоринга на оценённой схеме, сам редактор с палитрой в рейке. Для чата —
   либо ключ на время съёмки, либо блок остаётся иллюстрацией без подписи о
   подлинности. Это надо решить до фазы 1.
2. **Папки реестра** — светлая карточка, зелёный только как знак выбранной папки.
3. **Реестр на телефоне** — карточная раскладка строки ниже 640 px, таблица от 640 px.
4. **Цвет команды** — набор из шести марок токенов вместо нативной пипетки.
5. **Компания в профиле** — по умолчанию «Не указана»; значение по умолчанию, если оно
   нужно, пишется в данные при регистрации, а не рисуется в UI.

Стенд для проверок (одноразовый, не трогает пользовательские `bpmn.db` и порт 3456):

```
DATABASE_URL="sqlite:///./verify_tmp.db" PYTHONIOENCODING=utf-8 python main.py   # 8765
cd bpmn-constructor && npm start                                                 # 3456
```

Замеры — puppeteer-скриптом из `node_modules` (`setViewport`, токен в
`localStorage.token`), не встроенным браузером: он отдаёт `innerWidth = 0`.

## Что осталось открытым

1. **Мобильная композиция `/share`.** Холст влезает в экран на десктопе (высота считается
   от остатка окна), но на телефоне шапка с описанием и действием занимает 519 px, и до
   схемы надо доскроллить. Нужен ответ владельца: что режем на узких ширинах — описание,
   крупный заголовок или кнопку копирования уносим в панель масштаба.
2. **Скриншоты для галереи лендинга.** Сейчас под «путём схемы» один реальный экспорт
   диаграммы. Снимки текущего интерфейса лежат в `ui-final/` во временной папке; чтобы
   поставить их в `src/static/`, нужно разрешение — репозиторий публичный.
3. **Живой ИИ-чат без ключа GigaChat не снимается** (`/api/generate` отвечает 400).
   Либо ключ на время съёмки артефактов, либо чат остаётся без подписи о подлинности.
4. **Бэкенд-мелочи, найденные по ходу (не правились молча):** `TeamCreate.name` без
   границы длины (`app/schemas.py:136-138`) — перелёт даёт 500 вместо 422; `TeamResponse`
   не несёт `members_count` — список команд читает участников построчно;
   `core/bpmn_scoring.py:592` вшивает id элементов в текст рекомендации (на фронтенде
   это срезается `humanizeBpmnNote`, но правильнее чинить на источнике).
5. **Общий `Popover` в ките.** Шапка и редактор закрывают всплывающие слои похожими, но
   не одинаковыми механизмами (у шапки есть наведение и модальность ввода, у редактора —
   клик и `focusout`). Третьего потребителя пока нет, поэтому решение сознательно
   отложено: при появлении мигрировать оба в один хук.
